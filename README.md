# WINE AI — Full-stack starter

واجهة WINE AI عربية/إنجليزية-جاهزة (العربية افتراضياً) مع واجهة محادثة، وضع زائر، وتسجيل حساب بالبريد، وربط API الموجود في المشروع.

## ما يعمل في هذه النسخة
- واجهة متجاوبة للموبايل والكمبيوتر بهوية أسود/فضي/نبيتي.
- محادثة مع Gemini عبر API scraper المرفق، مع استمرار الجلسة باستخدام `sessionId` عند توفره.
- بدء جلسة زائر بتوكن JWT من السيرفر؛ لا يوجد مفتاح API داخل المتصفح.
- تسجيل/دخول بالبريد وكلمة المرور عبر MySQL.
- حفظ سجل المحادثات محلياً في المتصفح.

## تنبيه مهم حول محرك الذكاء الاصطناعي
ملف Gemini الأصلي يستخدم نقاط اتصال ويب خاصة وغير موثقة، وقد تتغير أو تتوقف في أي وقت. هذا ليس Gemini API الرسمي ولا يوجد ضمان لاستمرارية عمله. لا تعتبر AI Vision أو Claude متاحين في هذه النسخة؛ لم يتم تفعيلهما في الواجهة.

## التشغيل محلياً
يتطلب Node.js 20 أو أحدث وMySQL لحسابات البريد.

1. أنشئ قاعدة بيانات MySQL باسم `wine_ai` ثم نفّذ `database/schema.sql`.
2. انسخ `.env.example` إلى `.env` واملأ `JWT_SECRET` (32 حرفاً عشوائياً على الأقل) وبيانات MySQL. يمكن ترك `ALLOWED_ORIGINS` فارغاً عند تشغيل الواجهة والـ API من نفس الأصل.
3. ثبّت الاعتماديات وشغّل الخادم:

```bash
npm install
npm start
```

4. افتح `http://localhost:3000`. فحص الصحة: `http://localhost:3000/health`.

## النشر على Vercel + GitHub
1. ارفع محتويات هذا المجلد إلى مستودع GitHub.
2. استورد المستودع في Vercel، واترك Framework Preset على Other. لا تحتاج Build Command للواجهة الثابتة.
3. أضف متغيرات البيئة في Vercel: `JWT_SECRET`، وبيانات MySQL (`DB_HOST`, `DB_USER`, `DB_PASSWORD`, `DB_NAME`, `DB_PORT`, `DB_SSL`).
4. أضف `ALLOWED_ORIGINS` فقط إذا كان الـ API سيُستخدم من نطاق آخر، واكتب نطاق الواجهة بالكامل.
5. نفّذ `database/schema.sql` على قاعدة البيانات قبل تجربة تسجيل الحسابات.
6. أعد Deploy، ثم افتح `/api/health` واختبر بدء جلسة الزائر من الواجهة.

## نقاط أمان وتشغيل
- لا تضع أسراراً في `app.js` ولا ترفع ملف `.env` إلى GitHub.
- جلسة الزائر تستخدم عداداً داخل ذاكرة عملية Node؛ قد يُعاد ضبطه مع إعادة تشغيل Serverless Function، لذلك لا تعتبره نظام حصص إنتاجياً دائماً.
- حسابات البريد وحصص المستخدمين تعتمد على MySQL.
- استخدم قاعدة بيانات وخادماً موثوقين، ودوّر الأسرار فور الاشتباه بتسريبها.
- إعدادات Vercel وحدود مدة التنفيذ تتغير حسب الخطة؛ قد يتجاوز طلب Gemini مدة تنفيذ الوظيفة.

## ملفات المشروع
- `index.html`, `styles.css`, `app.js`: واجهة WINE AI.
- `api/guest.js`: إصدار جلسة زائر موقعة.
- `api/chat.js`: واجهة المحادثة.
- `api/auth.js`: التسجيل وتسجيل الدخول.
- `src/lib/scrap/ai/gemini.js`: محرك Gemini المرفق (غير رسمي).
- `database/schema.sql`: جداول المستخدمين ومحددات المعدل.
